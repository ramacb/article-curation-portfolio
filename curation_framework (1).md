# Curation Framework Checklist

Use this structured workflow to transform scattered internet links into a premium content asset.

### 🔍 Phase 1: Resource Discovery
- [ ] Query primary search engines using targeted exact-match keywords.
- [ ] Monitor industry-specific forums and news aggregators (e.g., Medium, Reddit, TechCrunch).
- [ ] Identify 10–15 candidate URLs relevant to the assignment brief.

### 🛡️ Phase 2: Filtration & Quality Control
- [ ] **Authority Check:** Verify the author or publisher's credentials.
- [ ] **Recency Check:** Ensure the data or article was published within the required timeline.
- [ ] **Fact-Checking:** Cross-reference statistics and technical claims with primary sources.
- [ ] Narrow the final selection down to the top 3–5 highest-value items.

### ✍️ Phase 3: Composition & Value Add
- [ ] Draft a clean, compelling introductory hook for the audience.
- [ ] Summarize each chosen asset in 2–3 precise sentences.
- [ ] Highlight the specific takeaway (*The "Why This Matters" factor*).
- [ ] Ensure formatting remains highly scannable using clear visual anchors.
